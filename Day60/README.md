## 📌 Overview

**Prompt Puzzle** is an interactive educational application that helps users practice **AI prompt engineering through puzzle-based challenges**.

Instead of learning prompting only through theory, the application turns prompt creation into an active learning experience where users can experiment, solve challenges, receive feedback, and improve their prompting skills.

The project was developed as the **10-Day Capstone Sprint** of the **AB Talks 60-Day Claude AI Challenge**.

The capstone represents the complete Software Development Lifecycle — from idea and requirements gathering to product development, UI/UX refinement, testing, debugging, deployment, documentation, and release.

---

## 🎯 Project Goals

* Make prompt engineering easier for beginners to practice.
* Turn abstract prompting concepts into interactive challenges.
* Encourage experimentation and iterative improvement.
* Provide a structured learning experience.
* Demonstrate practical AI-assisted software development.
* Deliver a polished, production-ready MVP.

## ✨ Key Features

Learn practical prompting concepts while solving challenges.

### 📊 Progress Tracking

Track performance and improvement while working through the learning experience.

### 🎮 Gamified Experience

Puzzle-style interactions make learning prompting more engaging and less intimidating.

### 💻 Responsive Interface

Designed to provide a consistent experience across desktop and smaller screens.

### 🌙 Modern UI

A polished dark-themed interface with interactive cards, visual feedback, and a modern product aesthetic.
