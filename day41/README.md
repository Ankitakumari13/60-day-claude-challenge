# 🚀 Day 41/60 — ABTalks 60-Day Claude Challenge

## 📊 Interactive Learning Studio — Power BI Fundamentals

An interactive, project-based learning platform designed to teach **Power BI Fundamentals: From Data to Dashboard** through hands-on modules, quizzes, practical exercises, and a final dashboard challenge.

This project was created as part of the **ABTalks 60-Day Claude Challenge**.

---

## 🎯 Project Objective

The goal of this project is to make Power BI learning more **interactive, practical, and engaging** rather than simply providing a traditional learning roadmap.

The learner progresses from understanding Power BI fundamentals to building and explaining a complete **Sales Analytics Dashboard**.

## 🧩 Learning Modules

### Module 1 — Foundation

Learn the fundamentals of Power BI and understand the complete journey from raw data to an interactive report.

Topics include:

* What is Power BI?
* Power BI Desktop vs Power BI Service
* Data sources
* Power Query introduction
* Data exploration
* Business questions
* Data-to-dashboard workflow

---

### Module 2 — Prepare & Model

Learn how to prepare data and build a reliable analytical model.

Topics include:

* Data cleaning
* Data types
* Duplicate records
* Missing values
* Power Query workflow
* Fact and dimension tables
* Relationships
* Star schema
* Date dimensions

---

### Module 3 — Visualize & Analyze

Learn how to turn data into meaningful insights.

Topics include:

* DAX fundamentals
* Measures
* Calculated columns
* KPIs
* Profit Margin
* Filter context
* Choosing the right visualization
* Trend analysis
* Category comparison
* Data storytelling

Example measures:

```DAX
Total Sales = SUM(Sales[Sales])

Total Profit = SUM(Sales[Profit])

Orders = DISTINCTCOUNT(Sales[OrderID])

Customers = DISTINCTCOUNT(Sales[CustomerID])

Profit Margin = DIVIDE([Total Profit], [Total Sales])
```

---

### Module 4 — Dashboard Project

Build a complete **Sales Analytics Dashboard**.

The project focuses on:

* KPI cards
* Sales trends
* Category analysis
* Regional analysis
* Top products
* Interactive slicers
* Dashboard layout
* Visual hierarchy
* Business insights
* Dashboard testing

---

## 🏆 Final Challenge

The learner must build a one-page Sales Analytics Dashboard from scratch.

### Challenge Requirements

* Import and clean data
* Build a suitable data model
* Create DAX measures
* Add at least 5 KPIs/visuals
* Add interactive slicers
* Create meaningful visualizations
* Write at least 3 business insights
* Explain the reasoning behind dashboard design decisions
