# 🚀 AI Workflow Architect

### Day 43/60 — ABTALKS 60 Day Claude Challenge

> **Design. Automate. Accelerate.**

**AI Workflow Architect** is a premium, single-page workflow platform designed to transform a complex **Data → SQL → Power BI** project into a structured, end-to-end execution workflow.

It helps learners and aspiring data professionals understand **what to do, which AI tools to use, what prompts to write, what mistakes to avoid, and what outputs to produce at every stage.**

---

## 🎯 Project Objective

The goal of this project is to create a **portfolio-ready Business Intelligence workflow** that guides users from initial business requirements to final project presentation.

### Workflow

```text
Business Requirements
        ↓
SQL Data Preparation
        ↓
Power BI Data Modeling
        ↓
DAX Measure Development
        ↓
Dashboard UX & Visualization
        ↓
Validation & QA
        ↓
Insights & Storytelling
        ↓
Portfolio Project Packaging
```

## 💡 Example AI Prompts

### SQL

```text
Review this SQL transformation for correctness, edge cases,
performance, and data-quality risks. Suggest validation queries.
```

### Power BI Data Modeling

```text
Given these tables and relationships, propose a Power BI star schema,
date table, relationships, and naming convention.
```

### DAX

```text
Write a robust DAX measure for this KPI.
Explain filter context, assumptions, edge cases,
and how to validate it against SQL.
```

### Dashboard Design

```text
Design a 3-page Power BI dashboard for these KPIs.
Give each page a purpose, visual hierarchy, filters,
interactions and expected insight.
```

### Portfolio README

```text
Create a recruiter-friendly README for this Power BI project
covering the problem, dataset, SQL, data model, DAX,
dashboard pages, insights, limitations and future work.
```
