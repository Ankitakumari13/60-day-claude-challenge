## 📌 Overview

Making difficult decisions can be overwhelming.

This project is an AI-powered **Decision Report Dashboard** that guides users through a structured decision-making process by comparing multiple options, identifying hidden assumptions, evaluating risks, and generating a practical action plan.

Built as **Day 45/60** of the **ABTalks 60-Day Claude Challenge**.

---

## ✨ Features

- 🎯 Define the real decision
- ⚖️ Compare multiple options
- 🧩 Identify hidden assumptions
- 🧠 Detect cognitive biases
- 📊 Interactive Decision Matrix
- ⚠️ Premortem Analysis
- 📅 7-Day Validation Plan
- 🏆 AI-generated Verdict
- 📱 Responsive Dashboard Design
- 🌙 Modern Dark UI
