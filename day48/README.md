# ⚖️ Compare & Decide Builder

> **Research. Compare. Decide with Confidence.**

A premium single-page decision support application that helps users compare multiple options using **real research, transparent sources, and customizable decision weights**.

Instead of relying on fixed rankings, users can adjust what matters most to them and instantly see how the results change.

---

# ✨ Features

* 📊 Compare multiple products side-by-side
* ⚖️ Adjustable criteria weights
* 📈 Live ranking updates
* 📚 Transparent source citations
* 🔍 Research methodology section
* 📱 Fully responsive design
* 🌙 Modern dark UI
* 🚫 No external libraries
* ⚡ Runs completely offline
* 📄 Single HTML file

# 🚀 How It Works

1. Compare multiple options.
2. Adjust the importance of each criterion.
3. Watch rankings update instantly.
4. Review detailed comparison data.
5. Verify every data point using the listed sources.
6. Read the research methodology for complete transparency.

---

# 📊 Decision Criteria

The application supports customizable weighting for criteria such as:

* 💰 Price / Value
* ⚡ Performance
* 💻 Coding & Software Suitability
* 🎒 Portability

Additional criteria can easily be added by extending the JavaScript data model.

# 🔍 Research Transparency

One of the core goals of this project is **trust**.

The application includes:

* Source citations
* Research notes
* Data verification
* Estimate warnings (when applicable)
* Conflict resolution notes

Users can clearly distinguish between:

* ✅ Verified data
* ⚠️ Estimated values
* 🧮 Derived scores
